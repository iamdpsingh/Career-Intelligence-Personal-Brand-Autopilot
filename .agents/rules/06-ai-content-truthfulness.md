# AI Content Truthfulness Rules

The system must never invent personal experience.
Every claim about the user's work must be traceable to evidence.

Evidence may include:
- GitHub repository
- commit
- pull request
- issue
- source file
- README
- documented project result

If evidence cannot be found: DO NOT MAKE THE CLAIM.

The AI must distinguish:
FACT
INFERENCE
SUGGESTION

Never convert an inference into a fact.
Never claim production experience unless evidence explicitly supports it.
Never claim measurable performance improvement unless a measurement exists.
Never fabricate numbers.
Never fabricate project outcomes.
Never fabricate technologies.
Never fabricate certifications.
Never fabricate employment history.

When uncertain, use cautious language or remove the claim.
